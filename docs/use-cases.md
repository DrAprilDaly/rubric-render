# Rubric Render Use Cases

## UC-001 — Convert a Rubric

**Actor:** Instructor

**Precondition:** Instructor has rubric source data.

**Flow:**
1. Instructor opens `rubric-render.html`.
2. Instructor provides rubric data.
3. Application parses the data.
4. Application renders the rubric in the output section.
5. Instructor reviews the generated content.
6. Instructor copies the resulting text.

**Related requirements:** RR-FR-001, RR-FR-005
