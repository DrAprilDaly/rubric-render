# Rubric Render

Rubric to HTML, Markdown Converter

## Purpose

Reads a Brightspace rubric component XML file and generates either HTML or Markdown for use in documents.

## Current Status

Early proof of concept. Currently tested only with synthetic files modeled on Brightspace rubrics_d2l.xml schema version v2011.
